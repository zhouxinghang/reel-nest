Status: ready-for-agent

## 目标

收敛到一个可运行、可验证、无历史兼容分支的实现，完成完整回归和当前态文档；不把代码交付自动扩大成真实环境部署。

## 范围

- 按 spec 第 12.1 节逐项删除旧 app 业务实现、旧字段/别名、迁移初始化、整数 MetaTube 映射、旧资料源环境导入、旧 Compose 与升级脚本。
- 清除前端旧广播、re-export、未使用卡片、重复 CSS 和仅历史兼容测试；保留文件安全、有效刷新、家庭账号 _FILE、只读/读写挂载分工。
- 检查 module 依赖方向，App 仅装配，provider 无 SQL，handler 不承载文件安全或业务事务。
- 将 README 与 docs/api.md 重写为已实现当前态；历史 issue 和旧验证记录保留，新增本次验证记录及切换/回退步骤。
- 完成最终自动化与性能验证，分别记录真实服务/容器/播放器的已测和未测情况。

## Acceptance criteria

- [ ] 新前后端只有一套运行路径；没有把旧单体改名保留、兼容双写或服务端旧契约兜底。
- [ ] 所有删除项通过引用和回归核验；纯迁移代码已删除，新版本正常重启及状态持久化仍成立。
- [ ] 契约生成检查、前端 build/unit、Go test/race/vet、Playwright、格式和 diff 检查通过并留结果。
- [ ] spec 第 11 节性能门槛有可复跑数据；未达标项明确记录且不把未完成任务标记 resolved。
- [ ] Docker 可用时验证非 root、只读/读写挂载和持久化；不可用时明确列为未验证，不以配置文件存在代替实测。
- [ ] 安全说明保留永久删除不可恢复、外部文件系统竞态、长期串流凭证风险及真实播放器兼容性边界。
- [ ] 新空 DATA_DIR、不导入旧状态、拒绝旧 schema、不自动清空现有数据和备份/回退说明完整。
- [ ] 无真实凭据/媒体操作、无自动服务重启或部署；如用户另行授权部署，单独记录该动作与验证。
- [ ] 六个 issue 的 Answer、状态、地图和 Frontier 与实际完成情况一致。

## 验证与交付

完整执行本任务列出的门禁，并对照 R01–R12 逐项说明交付证据。最终回答区分代码完成、测试通过与部署状态；不能用“已通过评审”代替任何实现或验收证据。
