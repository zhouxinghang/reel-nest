# 02：文件安全、身份与媒体编目

Status: ready-for-agent
Blocked by: 01

Parent: [全量重构技术方案](../spec.md)

## 目标

建立有真实文件安全保障的 module seam，完成新建媒体库、身份会话、扫描、季集组织及持久化闭环，保留原实现的高价值安全行为。

## 范围

- 提取 `mediafs` 的根目录/逐级句柄访问、身份/指纹、视频/字幕安全打开及单文件 unlink 能力，业务调用者不能拿已校验路径再自行打开。
- 迁移家庭账号、会话、同源保护、登录限流，隔离会话和串流只读权限。
- 实现媒体库配置、名称、根范围/重叠检查、保守文件名识别和季集关系；本地组织不依赖线上资料。
- 实现 scan_runs/staging、有界 worker、每库变更互斥和完整发布事务；跨库不共享遍历锁。
- 落实 DATA_DIR 单进程锁、任务领取/停止/关闭顺序，保留家庭状态相关持久化基础。

## Acceptance criteria

- [ ] 真实临时媒体完成登录→建库→首次扫描→文件/季集查询→安全打开；未配置任何资料源也可完成。
- [ ] 名称校验、同名库隔离、目录重叠/越界/符号链接、根替换、特殊文件与应用数据重叠均正确处理。
- [ ] 同路径同版本重扫不改变 ID、收录时间、进度或收藏；新版本不继承旧文件身份。
- [ ] 完整成功扫描才移除缺失文件及依赖/空电视剧；任何中断/部分读取失败不发布部分结果。
- [ ] 文件清单与目录读取分批、有界；同库任务互斥、跨库可并行；进度/读取不等待整个扫描锁。
- [ ] 扫描、组织和资料目标变更的原子性及失败回滚通过真实 SQLite 测试。
- [ ] S01E01、作品目录内纯数字、季目录、多版本及保守未组织规则通过回归。
- [ ] 重启正确处理 interrupted 扫描；不自动扫描、不重复初始化账号、不让两个进程使用同一 DATA_DIR。
- [ ] 为任务 03、05 提供可测试的安全读取/删除能力，原有路径安全测试覆盖保留。

## 验证与交接

使用真实临时文件/SQLite、进程重启/中断及 race 测试。删除相关底层测试仅操作临时视频；HTTP 二次确认与前端交互由任务 05 集成，不在此任务省略其安全要求。
