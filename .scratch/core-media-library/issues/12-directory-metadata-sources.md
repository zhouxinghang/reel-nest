# 12: 按媒体目录配置影片资料源与优先级

Status: resolved
Blocked by: 07, 08

## 需求

2026-10-01 用户要求增加 TheMovieDB、TheTVDB 数据源，支持按文件夹配置并按优先级下载。现有 TMDB 能力扩展为两种影片资料源；下载指资料及海报，不涉及视频片源下载，不改变 ADR 0002 的媒体文件边界。

## Acceptance criteria

- [x] 每个媒体目录独立启用、禁用和排序 TMDB / TVDB，新旧目录默认 TMDB → TVDB；空列表禁用自动获取。
- [x] 自动匹配依次尝试，未配置、失败、无唯一可靠结果时回退，成功后停止；按来源隔离缓存和 ID，保留手动选择、媒体身份及进度。
- [x] TVDB v4 支持 API key / 可选订阅 PIN，中文优先、英文或原文回退，安全海报缓存、有界请求、限流冷却及明确失败反馈。
- [x] 界面可新增/编辑目录资料源，手动匹配展示来源，提供凭据和 API 文档。
- [x] 测试覆盖优先级、目录隔离、失败回退、缓存迁移和实际界面；外部服务使用可控替身，真实联通另列未验证。
