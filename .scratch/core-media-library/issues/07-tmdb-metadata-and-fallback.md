# 07: TMDB 影片资料与故障降级

**What to build:** 部署者配置自己的 TMDB 凭据后，电影与电视剧可获得中文优先的影片资料和海报；无凭据、资料不完整或在线服务失败时，家庭成员仍可按文件名与占位图浏览并实际播放本地媒体。

**Blocked by:** 03（电视剧、季与单集组织）；04（浏览器直放与家庭共用续播）

**Status:** ready-for-agent

**Parent:** [核心家庭媒体管理系统](/Users/bytedance/workspace/reel-nest/.scratch/core-media-library/spec.md)

**User stories:** 15, 21, 22, 23, 24, 25, 26, 57, 58

## 范围与边界

只接 TMDB，扫描与匹配分离。依赖 03 的内容组织和 04 的实际播放，故障降级验收不能仅检查“播放按钮仍存在”。不导入或写回本地 NFO。

## Acceptance criteria

- [ ] 提供部署者配置其自身 TMDB 凭据的方式和操作说明，不内置第三方个人凭据，也不向未授权页面或日志泄露凭据。
- [ ] 能为已扫描电影和电视剧匹配 TMDB 影片资料，海报墙与详情展示可用的标题、年份、简介和海报；电视剧资料不取代季、单集及实际媒体文件身份。
- [ ] 获取资料时优先中文，中文字段或图片缺失时合理回退到其他可用信息或本地文件名/占位图；不保证每部作品都有完整中文资料。
- [ ] 缺少凭据、凭据无效、网络超时、服务错误或限流均不会阻断文件扫描、本地媒体浏览与浏览器直放；对可观察到的资料获取失败给出明确反馈。
- [ ] 无可靠匹配时保留未匹配媒体，不把任意候选展示成确定答案；匹配失败不删除文件或媒体记录。
- [ ] 资料获取有合理的请求失败边界与限流处理，不能无限重试或持续阻塞用户浏览和播放；不将后台资料获取等同于用户要求的定时媒体扫描。
- [ ] 持久化影片资料来源与匹配结果；正常重启和重复扫描保留有效关联，不能重建媒体文件身份或重置已有浏览器观看进度。
- [ ] 遵循 TMDB 署名、限流与缓存要求，包括所获信息缓存不超过六个月；说明不能保证其资料永久离线保留，缓存失效或刷新失败仍不影响本地文件和观看进度。
- [ ] 仅将系统外部的 TMDB 替换成可控制测试服务，覆盖正确匹配、中文优先、缺少中文、无匹配、无凭据、超时、服务错误及限流；不模拟内部扫描、匹配存储、播放或数据库函数。
- [ ] 应用边界测试验证故障场景下仍能浏览并读取原始视频；浏览器测试至少覆盖无凭据和服务失败时的真实本地播放，以及成功匹配后的海报墙/详情。
- [ ] 交付本切片所需持久化、配置与资料接口、界面、测试、TMDB 设置及署名说明；将模拟服务测试与真实 TMDB 联通结果分开记录，手动修正由 08 完成。
