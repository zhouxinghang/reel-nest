# 06: 网页外挂字幕选择与关闭

**What to build:** 家庭成员在网页播放媒体时，可选择与视频匹配的同目录 UTF-8 SRT/VTT 外挂字幕，也可关闭字幕；损坏或不支持的字幕有明确反馈，不影响继续播放视频。

**Blocked by:** 04（浏览器直放与家庭共用续播）

**Status:** ready-for-agent

**Parent:** [核心家庭媒体管理系统](/Users/bytedance/workspace/reel-nest/.scratch/core-media-library/spec.md)

**User stories:** 33, 34, 35

## 范围与边界

仅提供浏览器外挂文本字幕。SRT 转为浏览器可用的字幕文本不属于视频转码；不提取内嵌字幕、不提供 ASS/SSA 特效或字幕烧录，也不依赖外部播放器串流。

## Acceptance criteria

- [ ] 发现与媒体文件名匹配的同目录 UTF-8 SRT/VTT 外挂字幕，说明匹配规则；多个匹配项提供可区分的选择，没有字幕时显示合理状态。
- [ ] UTF-8 VTT 可在网页播放器使用；UTF-8 SRT 经正确的文本格式转换后可使用，不能只更改扩展名就宣称兼容。
- [ ] 浏览器可选择、切换和关闭字幕，播放及拖动定位后字幕仍与时间轴对应；用真实可播放测试视频验证实际显示与关闭效果。
- [ ] 覆盖常见换行差异、字幕时间或结构错误、非支持编码；给出可理解反馈，不展示错误字幕为成功，也不因单个字幕错误阻断视频播放。
- [ ] 字幕获取需要网页授权，且只能访问指定媒体对应的目录内字幕；不能通过字幕标识读取任意文件或跟随越界符号链接。
- [ ] 字幕读取与转换不改写源视频或源字幕；无字幕、字幕关闭或错误情况下仍不进行视频转码。
- [ ] 通过真实应用与临时视频/字幕文件验证 SRT、VTT、多候选选择、关闭、无字幕、错误输入和未授权访问；比较操作前后源文件内容，验证无改写。
- [ ] 交付字幕识别与获取、播放器选择交互、必要数据关联、测试及格式边界说明；外部播放器自行加载字幕的边界不改变。
