# 04: 浏览器直放与家庭共用续播

**What to build:** 家庭成员从媒体文件详情进入浏览器，直接读取原始视频播放并拖动定位，离开后可继续家庭共用的已保存观看进度；浏览器不兼容或文件不可用时获得明确反馈。

**Blocked by:** 02（媒体目录扫描与基础媒体库浏览）

**Status:** resolved

**Parent:** [核心家庭媒体管理系统](/Users/bytedance/workspace/reel-nest/.scratch/core-media-library/spec.md)

**User stories:** 1, 4, 11, 28, 29, 30, 31, 32, 57

## 范围与边界

不依赖电视剧层级或 TMDB。只记录浏览器观看进度，不进行服务器视频转码。故事 30 的浏览器失败提示在本项交付，实际外部播放器唤起及复制链接由 05 完成。

## Acceptance criteria

- [x] 支持从已扫描媒体文件的基础详情进入网页播放器；无影片资料也能尝试播放，浏览器支持的测试视频可直接播放，不先要求下载完整文件。
- [x] 媒体读取需要有效网页身份，限制在配置的媒体目录和指定媒体文件；拒绝任意路径、越界标识及符号链接逃逸，对文件缺失或目标变化明确报错而非读取其他文件。
- [x] 原始视频读取支持 HTTP GET、HEAD 和 Range：HEAD 不返回文件体，有效范围返回正确的部分内容与字节长度，无效范围和不可用文件返回明确错误；按需读取，不将整部大文件载入内存。
- [x] 通过真实浏览器和可播放测试视频验证开始播放、拖动定位及后续继续读取；不能仅以媒体接口返回成功代替实际播放和定位验证。
- [x] 浏览器无法播放容器或编码时显示明确不兼容提示及外部播放器使用建议；文件缺失或读取失败不得被全部误报为格式不兼容，不加入转码补救。
- [x] 浏览器播放过程中保存家庭共用观看进度，重新打开同一媒体时可从已保存位置继续；另一浏览器登录同一家庭共享账号可读到该进度，不创建个人进度。
- [x] 观看进度关联稳定媒体文件身份，重复扫描和使用同一应用数据正常重启后仍可恢复；不同实际文件的进度不能因标题相同而串用。
- [x] 通过运行中应用的公开接口、真实临时媒体与持久化验证鉴权、HEAD、有效/无效 Range、文件不可用、进度保存、跨浏览器共享、重复扫描和重启；不模拟内部文件读取或数据库函数。
- [x] 交付本切片所需持久化、媒体与进度接口、播放器界面、测试及兼容性说明；报告实际测试浏览器与媒体样本，不承诺所有片源可直放，不把未来外部播放当成已同步进度。
