# 18: 按目录分组的具名媒体库

Status: resolved
Blocked by: 02, 11, 12

## 需求

2026-10-02：媒体库按添加的目录分组展示，一个目录作为一个媒体库资源，创建时需要名称。

## Acceptance criteria

- [x] 新建目录必须填写 1–80 字符的媒体库名称，可修改名称；名称仅影响展示，不修改磁盘目录。
- [x] 旧目录使用文件夹名补全名称，重启保留名称、媒体身份、匹配、收藏及进度。
- [x] 首页每个目录独立展示卡片和最近添加内容，空库也可见；进入后仅浏览该目录的电影/电视剧/未组织文件。
- [x] 全局分类、搜索、收藏、最近添加按目录分组，保留季集组织、排序、列表视图及来源隔离。
- [x] 覆盖名称校验、授权、旧库迁移、同名目录隔离与浏览器桌面/窄屏流程；仅使用隔离临时媒体。


## Answer

- 2026-10-02：一个接入目录对应一个具名媒体库；新增名称必填、规范化校验、修改名称、旧数据原子迁移和单库查询范围。保留目录/文件 ID、季集、资料源配置、匹配、收藏与观看进度，不改写源目录。
- 首页按目录展示独立卡片（含空库）及最近添加栏；分类、搜索、收藏、最近添加按目录分组，支持范围切换、列表/海报、排序、刷新及浏览器返回。详情提供所属媒体库入口，同名目录/文件不合并。
- 全量 Go 测试（64 个应用测试及启动器测试）、25 个 Chrome 流程、最终相关 race、vet、生产构建、Prettier 和 diff 检查通过。新增浏览器流程另单独运行两次，桌面与窄屏截图已目视检查。
- 仅使用临时媒体、数据库与隔离测试服务；没有修改用户媒体、读取真实凭据或重启既有服务。README、API、领域词汇和验证记录已同步，ADR 与父规格不变，未创建 commit。
