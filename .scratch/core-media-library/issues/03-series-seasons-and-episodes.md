# 03: 电视剧、季与单集组织

**What to build:** 家庭成员能区分电影与电视剧，在本地文件名识别结果的基础上按“电视剧 → 季 → 单集”找到具体视频；不能可靠识别的内容仍能从未匹配媒体进入文件详情。

**Blocked by:** 02（媒体目录扫描与基础媒体库浏览）

**Status:** ready-for-agent

**Parent:** [核心家庭媒体管理系统](/Users/bytedance/workspace/reel-nest/.scratch/core-media-library/spec.md)

**User stories:** 14, 16, 17, 18, 19, 20

## 范围与边界

只组织已有媒体文件，不等待 TMDB 资料，也不要求播放器已完成。领域命名遵循电影、电视剧、季、单集和媒体文件的区分。

## Acceptance criteria

- [ ] 海报墙或等价浏览入口明确区分电影与电视剧；详情提供电视剧、季、单集的逐级导航，每个可观看条目可定位到具体媒体文件。
- [ ] 能识别文件名中的常见季集标记，如 S01E01；季与单集按季号、集号合理排序，不仅按文件名字符串排序，并说明采用的识别规则。
- [ ] 一个媒体文件只承载一部电影或一个单集，不将多集合一文件伪装成多个独立可操作文件。
- [ ] 不同实际视频文件即使对应同一作品或季集编号也保留独立身份和可区分入口，不自动合并版本；不能只靠标题或季集编号唯一定位实际文件。
- [ ] 无法可靠确定作品或季集编号的内容保留为未匹配媒体，仍可浏览并打开该媒体文件，不强行套用任意电视剧。
- [ ] 组织结果在重复扫描及正常重启后保持一致；不改变原始文件名、不移动文件，也不依赖磁盘目录一定与作品层级相同。
- [ ] 通过真实应用和隔离媒体目录验证电影/电视剧分类、跨季导航、季集数值排序、相同作品的不同文件版本及识别失败回退；浏览器测试覆盖从海报墙到具体单集详情。
- [ ] 交付组织结果所需的持久化、接口、界面与测试；后续播放和删除通过稳定媒体文件身份接入，不在本项新增播放器或删除入口。
