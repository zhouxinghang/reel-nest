# 08: 手动修正影片资料匹配

**What to build:** 家庭成员发现电影或电视剧资料匹配错误、或者内容仍未匹配时，可在网页搜索 TMDB 候选并明确选择正确作品，更新显示资料而无需改名或移动视频。

**Blocked by:** 07（TMDB 影片资料与故障降级）

**Status:** resolved

**Parent:** [核心家庭媒体管理系统](/Users/bytedance/workspace/reel-nest/.scratch/core-media-library/spec.md)

**User stories:** 27

## 范围与边界

仅修正影片资料关联，沿用 07 的中文优先、故障降级与外部服务约束，不增加资料供应方或本地 NFO 编辑。

## Acceptance criteria

- [x] 已登录用户可从错误匹配或未匹配内容进入手动匹配，搜索 TMDB 并看到足以区分作品的候选信息，例如作品类型、标题、年份与可用海报。
- [x] 支持为电影或电视剧选择对应类型的候选，不把一部电视剧误关联为电影，也不通过匹配把多个实际文件合并成一个。
- [x] 用户明确选择候选后，海报墙与详情显示所选影片资料；取消选择、无结果或请求失败时保持原来的有效状态，不误报匹配成功。
- [x] 手动修正仅改变影片资料关联，不重命名、移动或改写原始视频；保留稳定媒体文件身份、不同版本的独立性、季集关系和既有观看进度。
- [x] 正常重启和重复扫描后手动选择仍保留，自动匹配不得在无用户选择的情况下把它恢复成先前错误结果。
- [x] 所有搜索和确认匹配操作均校验家庭共享账号；TMDB 超时、限流或无凭据时给出反馈，本地浏览与播放仍可使用。
- [x] 通过真实应用、临时媒体及可控制 TMDB 服务验证误匹配修正、未匹配补全、电影/电视剧候选、取消、无结果、服务失败及越权；操作前后核对源文件、媒体身份与观看进度不变。
- [x] 浏览器测试覆盖搜索、选择到海报墙/详情更新的完整路径，重启与重扫测试覆盖手动选择保留；交付所需数据关联、接口、界面、测试和修正使用说明。

## Answer

- 2026-09-30：交付同类型候选搜索与显式确认接口、电影/电视剧/单集详情中的原生匹配对话框。候选提供类型、标题/原始标题、年份和 TMDB 标识；搜索/选择本身不写关联，取消和失败保留有效状态，确认成功后更新海报墙与详情。
- 电影按独立媒体文件关联，电视剧按本地电视剧关联；未组织电视剧文件可独立补充整部作品资料，但不编造季集、不合并版本。源视频与字幕不改名、不移动、不改写，观看进度保持原样。
- 手动关联事务性保存并与后台自动匹配串行化；重扫/重启及缓存到期后始终保留用户选择的类型/TMDB ID。过期刷新失败只降级显示，不恢复成原来的自动结果。
- 新增 4 个 Go 应用级测试（包含电影/电视剧/未组织文件、无凭据/超时/限流等子用例），覆盖取消、无结果、误匹配修正、未匹配补全、类型/账号/串流权限隔离、失败保留、真实文件和进度不变、重扫/重启/缓存到期恢复。
- Chrome 覆盖电影与电视剧搜索→选择→确认→详情/海报墙更新、取消/无结果/失败和窄屏对话框；整套 7 流程通过，资料相关 3 流程各重复通过 3 次。完整测试、race/vet、格式、构建、交叉编译及真实旧播放版本升级验证见 [验证记录](/Users/bytedance/workspace/reel-nest/docs/verification.md)。
- 使用与接口说明已更新 README、docs/api.md。Docker 按用户要求跳过；真实 TMDB API 联通没有凭据，明确未验证。测试均为隔离临时媒体，未触碰用户已有媒体。父规格、领域术语及 ADR 不变；09 为下一 frontier，本轮未领取。
