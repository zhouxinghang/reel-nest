# 08: 手动修正影片资料匹配

**What to build:** 家庭成员发现电影或电视剧资料匹配错误、或者内容仍未匹配时，可在网页搜索 TMDB 候选并明确选择正确作品，更新显示资料而无需改名或移动视频。

**Blocked by:** 07（TMDB 影片资料与故障降级）

**Status:** ready-for-agent

**Parent:** [核心家庭媒体管理系统](/Users/bytedance/workspace/reel-nest/.scratch/core-media-library/spec.md)

**User stories:** 27

## 范围与边界

仅修正影片资料关联，沿用 07 的中文优先、故障降级与外部服务约束，不增加资料供应方或本地 NFO 编辑。

## Acceptance criteria

- [ ] 已登录用户可从错误匹配或未匹配内容进入手动匹配，搜索 TMDB 并看到足以区分作品的候选信息，例如作品类型、标题、年份与可用海报。
- [ ] 支持为电影或电视剧选择对应类型的候选，不把一部电视剧误关联为电影，也不通过匹配把多个实际文件合并成一个。
- [ ] 用户明确选择候选后，海报墙与详情显示所选影片资料；取消选择、无结果或请求失败时保持原来的有效状态，不误报匹配成功。
- [ ] 手动修正仅改变影片资料关联，不重命名、移动或改写原始视频；保留稳定媒体文件身份、不同版本的独立性、季集关系和既有观看进度。
- [ ] 正常重启和重复扫描后手动选择仍保留，自动匹配不得在无用户选择的情况下把它恢复成先前错误结果。
- [ ] 所有搜索和确认匹配操作均校验家庭共享账号；TMDB 超时、限流或无凭据时给出反馈，本地浏览与播放仍可使用。
- [ ] 通过真实应用、临时媒体及可控制 TMDB 服务验证误匹配修正、未匹配补全、电影/电视剧候选、取消、无结果、服务失败及越权；操作前后核对源文件、媒体身份与观看进度不变。
- [ ] 浏览器测试覆盖搜索、选择到海报墙/详情更新的完整路径，重启与重扫测试覆盖手动选择保留；交付所需数据关联、接口、界面、测试和修正使用说明。
