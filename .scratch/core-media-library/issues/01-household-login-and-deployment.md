# 01: 单机部署与家庭共享账号登录

**What to build:** 部署者在一台主机上运行应用，家庭成员通过局域网浏览器使用同一个家庭共享账号登录，看到受保护的空媒体库，并可退出。正常重启后无需重新建立应用配置。

**Blocked by:** None (can start immediately)

**Status:** resolved

**Parent:** [核心家庭媒体管理系统](/Users/bytedance/workspace/reel-nest/.scratch/core-media-library/spec.md)

**User stories:** 1, 2, 3, 5, 55, 57, 58, 60

## 范围与边界

这是可运行、可演示的登录与部署闭环，不是单独的脚手架任务。遵循 ADR 0002：媒体接入边界为宿主机预先挂载的目录；本项不实现扫描或媒体播放。

## Acceptance criteria

- [x] 提供单机 Docker 部署入口及最小启动说明，说明应用数据持久化位置、媒体挂载方式与局域网访问方法；空媒体库不要求先配置 TMDB 或接入 NAS。
- [x] 提供家庭共享账号的配置与账号密码登录；正确凭据可进入空媒体库，错误凭据被拒绝，界面明确展示未接入媒体的空状态。
- [x] 未登录访问受保护页面和应用接口时被拒绝或引导登录；不能仅依靠前端隐藏入口实现访问控制，密码不得暴露在前端资源或日志中。
- [x] 退出使当前会话失效；重新使用该会话请求受保护内容不能继续成功。
- [x] 不同浏览器登录同一家庭共享账号后访问同一应用状态；不建立个人账号、成员档案、分库或权限等级。
- [x] 应用配置与授权所需持久化数据独立于媒体目录；使用同一应用数据正常重启后仍可按原配置登录，不要求已有登录会话必须跨重启保留。
- [x] 以隔离配置启动真实应用，通过公开 HTTP 验证错误凭据、未登录访问、登录、退出和重启；以少量浏览器测试验证可见登录闭环，不模拟内部授权或持久化函数。
- [ ] 在具备 Docker 的环境验证容器启动、局域网访问配置与应用数据持久化；记录实际环境和结果，缺少环境时明确列为未验证，不能用本机进程启动代替容器实测。
- [x] 交付本切片所需的持久化、应用接口、界面、测试和使用说明；不增加注册、找回密码、分布式部署或其他平台能力。
