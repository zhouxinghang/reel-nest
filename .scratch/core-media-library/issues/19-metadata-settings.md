# 19: 页面配置影片资料源

Status: resolved
Blocked by: 12, 17

## 需求

2026-10-02：将影片资料源配置放在页面中，替代原有环境变量配置。

## Acceptance criteria

- [x] 家庭共享账号可在管理页面配置 TMDB Token、TVDB API Key / PIN、MetaTube 地址 / Token；保留每目录启用和优先级。
- [x] 服务端持久化，保存即时生效且重启保留；旧环境配置仅首次迁入，不覆盖后续修改或清除。
- [x] API/页面/日志不回显凭据；留空保持，清除需显式选择；防止旧页面覆盖较新的配置。
- [x] 校验地址及字段、同源授权；修改 MetaTube 地址不能将旧 Token 自动发送到新服务。
- [x] 保存失败和并发冲突保留现有设置、媒体身份、手动匹配、进度和收藏；覆盖 HTTP/SQLite/浏览器与 race 回归。

## Comments

- 资料源凭据以 AES-256-GCM 加密存入权限受限的应用 SQLite，密钥文件单独保存在数据目录；备份须按敏感数据保护。公共来源 API 地址仍固定，MetaTube 地址允许自部署 HTTP/HTTPS；不新增账号或权限角色。


## Answer

- 交付 `/settings/metadata` 页面与受同源家庭会话保护的 API；TMDB、TVDB、MetaTube 的服务地址/凭据由页面管理，保留目录独立启用和优先级。成功保存即时替换客户端，不需要重启或重扫。
- SQLite 以 AES-256-GCM 保存凭据，独立 0600 密钥；首次兼容迁入旧变量/凭据文件，之后不再读取或覆盖页面值。留空保留、显式清除、来源版本冲突与 MetaTube 地址变更的 Token 保护均已实现。
- 新增 5 个应用测试，验证真实 HTTP/SQLite、密钥丢失/恢复、地址篡改、保存失败、重启、并发更新及关联写入互斥。手动选择、媒体身份、观看进度、收藏及缓存回归保持。
- 全量 Go（69 个应用顶层测试及启动器测试）、27 个 Chrome 流程、全量及最终设置专项 race、vet、构建、格式与 diff 检查通过；桌面/手机截图已检查。详细命令和边界见 `docs/verification.md` 的 19 节。
- README、API 和旧 Compose 配置迁移说明同步更新。未安装依赖、未修改父规格/领域文档/ADR；自动化不操作用户媒体或真实资料源。按用户前述要求，提交后备份并重启本地应用，部署核验写入受限备份目录。
