# 02: 媒体目录扫描与基础媒体库浏览

**What to build:** 家庭成员登录后添加应用可访问的媒体目录，自动完成首次扫描，并在海报墙以文件名与占位图浏览媒体、打开对应文件的详情；之后手动扫描可发现新增内容。

**Blocked by:** 01（单机部署与家庭共享账号登录）

**Status:** resolved

**Parent:** [核心家庭媒体管理系统](/Users/bytedance/workspace/reel-nest/.scratch/core-media-library/spec.md)

**User stories:** 3, 6, 7, 8, 9, 10, 11, 12, 13, 18, 19, 20, 24, 56, 57, 58

## 范围与边界

遵循 ADR 0002。不依赖 TMDB、电影/电视剧精细组织或播放实现；本项建立后续能力共用的稳定媒体文件身份，未匹配媒体是正常可浏览状态。

## Acceptance criteria

- [x] 可添加宿主机已挂载并暴露给应用的本地或 NAS 媒体目录；部署说明区分宿主机路径与应用可见路径，说明读取权限，不提供 SMB/NFS 配置、上传或片源下载。
- [x] 新增媒体目录自动发起一次扫描，后续提供手动重新扫描；页面可观察运行中、完成、失败及可理解的错误，不加入定时扫描或实时监听。
- [x] 扫描发现的视频以文件名和占位海报进入家庭共用媒体库，可从海报墙打开单个媒体文件的基础详情；没有 TMDB 凭据或网络也可完成这一流程。
- [x] 为仍然相同的媒体文件维持稳定身份；重复扫描不重复收录、不重建身份；不同实际视频文件即使名称相似也不能被合并。
- [x] 无法可靠识别内容的文件保留为未匹配媒体，不因文件名不符合规则而隐藏；对支持的视频文件类型及识别边界提供说明，不承诺所有格式都能播放。
- [x] 媒体目录不可访问、挂载丢失、权限不足或扫描中断时显示错误，保留已有媒体记录，不把失败或不完整扫描当成全库删除；完整扫描确认缺失的文件不得继续被呈现为可用。
- [x] 目录接入、扫描和媒体查询均需要家庭共享账号授权；客户端提交的标识不能任意枚举或读取服务器文件，扫描不跟随逃出媒体目录的符号链接。
- [x] 媒体目录、文件身份和可用性在应用重启后保留；预留的身份契约不以显示标题或未来的 TMDB 标识代替文件身份。
- [x] 通过真实应用、临时媒体目录与真实持久化存储验证新增自动扫描、手动发现新增、重复扫描、未匹配展示、目录不可用和重启；等待可观察的扫描结束状态，不用固定延时伪造完成。
- [x] 用浏览器验证添加目录到海报墙和详情的完整路径；仅使用隔离测试文件，不修改用户媒体。
- [x] 交付本切片所需的持久化、接口、界面、测试和目录接入说明。观看进度及匹配结果的重扫保留分别由 04、07 在引入相应能力时补充验收，不作为本项隐藏依赖。
