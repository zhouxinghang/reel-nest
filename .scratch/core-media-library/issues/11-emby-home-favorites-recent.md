# 11: Emby 风格首页、家庭收藏与最近添加

**Status:** resolved

**What to build:** 按用户追加要求，首页采用 Emby 的全宽布局、顶部标签和横向媒体栏，新增家庭共享收藏与真实最近添加。

## 范围与边界

- 收藏面向家庭共享账号，电影、单集文件和整部电视剧分别持久化，不区分个人，不改变观看进度或源文件。
- 最近添加以实际成功扫描收录时间排序，重扫不刷新旧文件日期，新增单集使所属电视剧提前；历史未记录日期保持未知。
- 参考存档 `/Users/bytedance/Downloads/Archive/Media Server-server.html` 仅含详情页及共用 CSS，没有首页 DOM/截图。使用其配色、间距、卡片比例及页面结构规范，不能据此声称已通过首页逐像素比对。
- 不改变播放、字幕、串流与删除授权边界；串流凭证不能授权收藏。

## Acceptance criteria

- [x] 首页取消固定侧栏和宣传区；显示顶部标签、我的媒体、继续观看与最近添加媒体栏，支持横向滚动和窄屏。
- [x] 卡片与详情页可收藏/取消，收藏页筛选、排序与空态正确；失败不伪报成功，允许重试。
- [x] 跨浏览器及应用重启保留共享收藏，文件与整部电视剧相互独立；目标扫描移除时清理收藏。
- [x] 实际收录日期与文件修改时间分离，普通重扫和旧库迁移不伪造时间，新单集使电视剧排序提前。
- [x] 未登录、跨站及串流凭证不能写收藏；非法输入和不存在对象明确拒绝。
- [x] 原有登录、搜索、扫描、季集、播放、字幕、匹配和删除回归通过；更新说明与验证记录。

## Answer

- 收藏使用独立 SQLite 外键表保存文件/电视剧状态；接口幂等、会话鉴权及同源检查，失败允许重试，正常重扫与重启保留状态。
- 新扫描只为新文件写入毫秒级收录时间；旧库加列迁移保留未知日期；最近添加与系列摘要按真实日期排序，不冒充文件修改时间。
- 首页改为全宽顶部导航、16:9 媒体入口/续播和 2:3 海报横向栏；收藏与最近添加均有筛选、搜索、排序、列表/海报视图。搜索仍支持已归组电视剧的单集文件名。
- 全套 `npm test`（14 个 Chrome 流程）、全量 race、vet、格式和 diff 检查通过。4 个新增 Go 测试覆盖持久化、授权隔离、重扫稳定、单集聚合、级联清理与旧库迁移；浏览器验证两会话共享、等待/失败/重试、移除/空态和窄屏。
- 已备份数据库并更新 8090 服务；迁移后原账号、媒体、组织、资料和观看进度保持不变。实际桌面/窄屏首页与最近添加已验证，未播放、扫描或修改用户视频。
- 仅有详情页参考存档，首页逐像素一致性仍无法据此验证；Docker 与其他实机限制不变。详情见 `docs/verification.md`。
