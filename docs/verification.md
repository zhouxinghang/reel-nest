### 应用边界测试覆盖

- 错误凭据、未登录页面/接口拦截、正确登录、退出后旧会话重放失败；不同浏览器共用账号，退出一端不影响另一端。
- 用相同应用数据重启，无首次启动凭据时仍能登录原账号；不公开密码/哈希；跨站、表单、未知字段及多段 JSON 请求被拒绝。
- 添加媒体目录自动扫描、手动发现新增、重复扫描稳定标识、不同真实文件不合并、未匹配文件详情、文件名搜索、文件分类及重启持久化。
- 根目录失联、同路径空挂载点/根目录替换时失败且保留索引；完整扫描发现缺失后标记不可用；替换版本得到新标识。
- 非 root 进程下真实目录权限错误、恢复权限后重扫；部分扫描不能发布删除结果。
- 未授权目录/查询/扫描、越界路径、符号链接目录/文件（包括指向根内与根外）、重叠接入、无效媒体标识。
- 独立应用子进程收录原文件后，再发起包含 6000 个新增临时文件的扫描并强制终止；重启显示“扫描已中断”，旧索引保留，手动重试完成。

### 01–03 浏览器主流程（历史）

真实应用进程与隔离应用数据启动 → 未登录重定向 → 错误密码 → 登录空媒体库 → 添加临时媒体目录 → 观察扫描完成 → 海报墙 → 搜索/无结果 → 单文件详情和源路径 → 手动发现新增 → 目录失联显示失败 → 恢复重扫 → 原详情标识仍有效 → 添加电视剧目录 → 电视剧海报卡 → 第 0/2/10 季数值导航 → 第 2/10 集排序 → 同名文件的独立版本详情 → 返回对应季 → 多集合一文件回退详情 → 第二浏览器看到同一媒体库 → 退出和旧会话重放拒绝。

包含 1440×960 桌面及 390×844 窄屏截图与窄屏横向溢出检查；已检查媒体库与季集页面布局。01–03 阶段测试媒体是专门创建的文本占位文件（带视频扩展名），**只用于扫描/文件身份验证，不是可播放的视频样本**。

## 04–06 增量验证

### 公开 HTTP / 真实 SQLite / 隔离文件

- 新增 5 个应用级用例，总计 17 个：04 的 HTTP 范围/进度和危险路径用例、05 的只读授权用例、06 的字幕转换及权限/版本隔离用例。测试不调用私有解析/授权/存储函数。
- GET、HEAD、单段/后缀/开放尾部/多段 Range、有效范围的真实字节和 Content-Length/Content-Range、畸形/越界范围 416、未授权 401、未知标识 404。
- 真实文件缺失、换 inode、原地内容修改、根目录失联/替换、目录/FIFO、根内/根外符号链接、父目录符号链接、非 root 进程下真实读取权限错误均拒绝，不返回其他文件。
- 共享进度：两份独立会话读写同一进度，最后有效更新可观察；同名不同文件不串用；无效/缺字段/null/超范围/提前完成被拒绝；重复扫描、真实存储重启、完成及重播均保留正确状态。
- 只读串流：仅通过受保护 HTTP 获取凭证，无 Cookie GET/HEAD/Range；无效/缺失/篡改/重复 token、移用到另一媒体文件拒绝；无法获得网页身份、浏览、扫描、进度写入或管理权限。当前尚无删除实现，但 token 对 DELETE 请求仍是 401，09 落地需再补真实删除接口回归。
- 网页退出和正常重启不使串流链接失效；同一持久化密钥签发同一媒体的凭证稳定，没有过期字段或时间依赖。测试没有冒充数月真实运行记录。目标被替换/扫描为不可用后旧地址不能读新文件；签发/读取不更新观看进度。
- 17 种字幕样本覆盖 UTF-8 BOM、CRLF/CR/LF、SRT 实际时间戳转换、VTT 短时间戳/标识/NOTE/位置、重叠 cue、分秒越界、反向/乱序时间、非 UTF-8、NUL、缺文件头/分隔/正文、无内容、无效位置、STYLE/REGION 和 >2 MiB。
- 字幕原始内容和视频操作前后一致；候选基本名/语言后缀边界、无字幕、根内/外符号链接排除、权限、读取目标变化、另一文件字幕标识及仅串流凭证访问均验证。

### 真实浏览器与可播放样本

`npm run test:browser`：4 条流程全部通过，包括旧有账号/扫描/季集流程和新增的播放、外部入口、字幕流程。另执行 `npx playwright test tests/playback.spec.ts --repeat-each=3`：新增 3 条流程各连续通过 3 次（9 次）。

样本为仓库自生成动画 `tests/fixtures/playback.webm`：3,040,488 字节，60 秒，640×360、12 fps、720 帧 VP8/WebM，**无音轨**。由 `scripts/generate-playback-fixture.mjs` 使用本机 Chrome WebCodecs 编码，带真实 duration/keyframe/cues；不是文本占位文件或下载影片。不在服务端执行转码，不需要 Docker/FFmpeg。

- 播放计时前进，浏览器实际 decoded frames 增长；在 256 KiB/s 的真实 CDP 网络限速下拖动页面滑块到后部，观察新的非零字节 Range 请求、seeked 后时间及解码帧继续前进，防止用已下载全文件或只验证按钮替代串流定位。
- 暂停后读取真实服务端进度；另一独立浏览器登录并续播；播放结束后移出「继续观看」，再次打开从零开始；损坏容器显示解码提示、真实文件删除显示缺失提示。
- 中文/空格/URL 保留字符文件可获取可复制网络地址；IINA 参数完整编码、PotPlayer 地址不拼入文件名；读取警告、localhost 提醒、手动选择完整地址和复制兜底可见；无 Cookie 客户端通过该页面获得的地址读取，进度不变。没有触发或声称触发真实外部播放器。
- 在真实视频上显示 SRT 字幕，切换为 VTT，在时间轴后部显示对应 cue，关闭后无 active cue；错误字幕显示明确反馈且视频时间继续前进，再选择有效字幕可恢复。
- 通过原生 textTracks 的 showing/activeCues 和截图共同核实。已目视检查 SRT 中文字幕、定位后 VTT 英文字幕和关闭无字幕截图，以及 1440×960 桌面/390×844 窄屏布局；无横向溢出。

### 真实 03 → 播放版本升级
